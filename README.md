# Hi, I'm Alpay Aliyev

I'm a **backend developer** who enjoys building structured and functional applications.

I started coding at **14** with simple HTML pages. Not long after, I got into **backend development** and began building CRUD projects step by step. I'm currently studying **Digital Skills and Informatics Teaching** at Baku State University.

Along the way, I completed **Java SE (OCA)** and a **Spring Framework (Basics)** course at Ingress Academy. On top of that, I was selected for a **Cybersecurity** program at Code Academy — inside Baku State University — under a scholarship from the **Ministry of Science and Education of Azerbaijan**.

As a hobby, I also experiment with **Blender** — creating 3D assets and converting them into simple animations. And I occasionally try to keep up with **mobile development** through Android Studio.

My goal is to grow as a backend developer while building secure, well-structured applications under the hood.
